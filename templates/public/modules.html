System Breakdown

Three Dedicated Role Modules

Each user interacts with tailored workflows enforcing GTU university academic standards and strict permission boundaries.

Module 1

Administrator Module

1. Secure Login
Encrypted credentials check and session handling with 1-to-1 Django user hashing.
2. Manage Courses
Add, update, view, and delete courses across different semester curriculum requirements.
3. Manage Teachers
Register academic faculty, departmental assignment, email indexing, and access grants.
4. Manage Students
Maintain student directory, unique roll numbers, semester mapping, and enrollment status.
5. Assign Teachers
Map courses directly to designated instructors with foreign-key referential integrity.
6. Monitor Assignments
High-level institutional surveillance of all published assignments and submission status.
7. Reports & Analytics
Instant calculation of submission turnaround rates, class average marks, and late counts.
8. Profile & Logout
Manage administrative credentials, profile metadata, and safe session termination.
Module 2

Teacher Module

1. Secure Login
Faculty authentication providing immediate access to personal course portfolios.
2. Create Assignment
Post title, detailed description, course assignment, maximum marks, and due date.
3. Attach Resources
Upload reference question papers, project templates, and rubrics for student guidance.
4. Set Deadlines
Define precise cutoff timestamps automatically enforcing on-time vs. late submission flags.
5. View Submissions
Filter student work by Submitted, Late, Evaluated, or Pending status with 1-click download.
6. Evaluate & Grade
Award numerical marks strictly validated between 0 and maximum assignment marks.
7. Give Feedback
Deliver constructive remarks, code critique, and improvements directly to the student.
8. Announcements
Broadcast class reminders, submission extensions, and instructions across enrolled courses.
Module 3

Student Module

1. Signup & Login
Self-service registration with roll number verification and automatic semester course enrollment.
2. My Courses
Access enrolled subjects, course teacher details, and course-specific assignment streams.
3. View Assignments
Browse all pending, submitted, and past-due assignments with due date indicators.
4. Submit Work
Upload assignment files with client- and server-side validation (PDF, DOCX, ZIP, PNG; max 10MB).
5. Resubmit
Seamlessly replace or update submitted files up until the deadline before evaluation begins.
6. Track Status
Live color-coded status badges: Pending, Submitted, Late, Evaluated, and Returned.
7. Grades & Feedback
Inspect evaluated marks out of maximum points, score percentage, and teacher remarks.
8. Notifications
Receive real-time alerts for upcoming assignment deadlines and recently evaluated work.
