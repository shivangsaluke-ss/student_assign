Entity Relationships & Foreign Key Constraints

Teacher → Course (1:N) One faculty member can instruct multiple subjects. Cascade delete ensures courses stay tied to valid faculty.
Course → Assignment (1:N) Each subject contains multiple assignment tasks throughout the semester with independent due dates.
Student → Enrollment (1:N) Composite unique constraint on (student_id, course_id) prevents duplicate course registrations.
Assignment → Submission (1:N) Unique constraint on (assignment_id, student_id) guarantees exactly one official submission per student.
Submission → Evaluation (1:1) One-to-One foreign key relation with unique index ensures each submission receives exactly one faculty score and review.
Indexed Deadlines assignment.due_date is specifically indexed (MUL) for high-performance late-status queries.
