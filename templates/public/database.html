Relational Schema

Database Specification (8 Tables)

Strictly normalized 3NF MySQL relational database schema supporting the SAMS academic lifecycle with indexed foreign keys and integrity constraints.

Table 1

admin

PK: admin_id | 1:1 linked with auth_user
Sr. No Field Name Data Type Constraint Description
1 admin_id int Primary Key Represents the unique ID of the administrator.
2 admin_name varchar(50) Not Null Represents the full name of the administrator.
3 admin_email varchar(50) Unique Represents the institutional email of the administrator.
4 admin_password varchar(100) Not Null Represents the secure hashed password of the administrator.
5 admin_mobile varchar(15) Unique Represents the contact mobile number of the administrator.
Table 2

teacher

PK: teacher_id | 1:1 linked with auth_user
Sr. No Field Name Data Type Constraint Description
1 teacher_id int Primary Key Represents the unique ID of the teacher.
2 teacher_name varchar(50) Not Null Represents the full name of the teacher.
3 teacher_email varchar(50) Unique Represents the unique email of the faculty teacher.
4 department varchar(50) Not Null Represents the academic department (e.g. Computer Science).
5 teacher_password varchar(100) Not Null Represents the hashed login password of the teacher.
Table 3

student

PK: student_id | 1:1 linked with auth_user
Sr. No Field Name Data Type Constraint Description
1 student_id int Primary Key Represents the unique ID of the student.
2 student_name varchar(50) Not Null Represents the full name of the student.
3 student_email varchar(50) Unique Represents the email address of the student.
4 roll_no varchar(15) Unique Represents the institutional roll number (e.g. 3092).
5 semester int Not Null Represents the academic semester enrolled in (e.g. 5).
6 student_password varchar(100) Not Null Represents the hashed login password of the student.
Table 4

course

FK: teacher_id -> teacher(teacher_id)
Sr. No Field Name Data Type Constraint Description
1 course_id int Primary Key Represents the unique ID of the course.
2 course_name varchar(50) Not Null Represents the title of the academic course subject.
3 teacher_id int Foreign Key Represents the assigned instructor faculty ID.
4 semester int Not Null Represents the curriculum semester the course belongs to.
Table 5

enrollment

Unique: (student_id, course_id)
Sr. No Field Name Data Type Constraint Description
1 enroll_id int Primary Key Represents the unique ID of the enrollment record.
2 student_id int Foreign Key Represents the enrolled student ID.
3 course_id int Foreign Key Represents the enrolled course subject ID.
4 enroll_date date Default (Today) Represents the date when enrollment occurred.
Table 6

assignment

FK: course_id -> course(course_id) | Index: due_date
Sr. No Field Name Data Type Constraint Description
1 assignment_id int Primary Key Represents the unique ID of the assignment.
2 title varchar(100) Not Null Represents the title of the assignment.
3 description text Not Null Represents the problem statement and instructions.
4 course_id int Foreign Key Represents the course subject ID.
5 due_date datetime Not Null (Indexed) Represents the submission deadline timestamp.
6 max_marks int Not Null Represents the total maximum marks points.
7 file_path varchar(200) Optional / Nullable Represents the optional teacher attachment file path.
Table 7

submission

Unique: (assignment_id, student_id)
Sr. No Field Name Data Type Constraint Description
1 submission_id int Primary Key Represents the unique ID of the submission.
2 assignment_id int Foreign Key Represents the assignment being submitted for.
3 student_id int Foreign Key Represents the student who uploaded the work.
4 file_path varchar(200) Not Null Represents the path of the uploaded file on the server.
5 submitted_at datetime Default (Now) Represents the timestamp when the file was uploaded.
6 status varchar(20) Not Null Pending, Submitted, Late, Evaluated, or Returned.
Table 8

evaluation

1:1 FK: submission_id (Unique)
Sr. No Field Name Data Type Constraint Description
1 evaluation_id int Primary Key Represents the unique ID of the evaluation.
2 submission_id int Foreign Key (Unique) Represents the unique evaluated submission record.
3 marks int Not Null Represents the numerical marks awarded (0 to max_marks).
4 feedback varchar(250) Not Null Represents the faculty teacher constructive feedback.
5 evaluated_on date Default (Today) Represents the calendar date of grading evaluation.
