01

Role-Based Segregation

Strict decorator-enforced permissions ensure Admins, Teachers, and Students only view authorized resources. Any unauthorized URL attempt returns a hardened 403 Forbidden page.

  • Dedicated left sidebar dashboards
  • Automatic redirection on login
  • Secure password hashing
02

5-Stage Status Lifecycle

Assignments travel through transparent stages: Pending → Submitted → Late → Evaluated → Returned, visible via color-coded badges to both students and teachers.

  • Automatic deadline late detection
  • Multi-format uploads (PDF/DOCX/ZIP)
  • Strict 10MB server validation
03

Analytics & Grading

Faculty review submissions in real-time, inspect files, allocate marks within maximum bounds, and issue constructive feedback that updates the student gradebook instantly.

  • Course submission rate metrics
  • Average marks & late distributions
  • Instant notification bells
